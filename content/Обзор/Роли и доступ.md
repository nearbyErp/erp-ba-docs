> [!info] Кратко
> В системе **нет фиксированных должностей** (кассир / менеджер / администратор как жёсткие роли — упразднены). Есть **настраиваемые роли-наборы прав** и вычисляемая **область видимости (scope)** — какие данные сотрудник видит. Это ориентир; полная модель — в домене [[Пользователи и доступ]].

## Две независимые вещи

Доступ = **что можно делать** (права) × **над какими данными** (scope). Их считают отдельно.

| Понятие | Что это | Пример |
|---|---|---|
| **Право (permission)** | Атомарное разрешение на действие | `catalog.edit`, `pos.access`, `stores.read` |
| **Permission-роль** | Именованный набор прав, назначается сотруднику с привязкой к точкам | «Старший смены», «Бухгалтер» |
| **Scope (область видимости)** | Множество данных, которые сотрудник видит | «вся франшиза» / «свои ЮЛ» / «две точки» |

Один сотрудник может иметь несколько ролей (каждую — на своём наборе точек). Итоговые права — объединение.

## Как считается scope

Ключевой момент для аналитика: **видимость определяется владением юрлицом, а не ролью.**

| Условие | Что видит | Типичный носитель |
|---|---|---|
| Сотрудник — владелец ЮЛ, и это ЮЛ — франшиза | **Вся франшиза**: все точки, ЮЛ, сотрудники | Владелец бренда |
| Сотрудник — владелец ЮЛ, и это ЮЛ — франчайзи | **Свои ЮЛ + их точки + их сотрудники** | Партнёр-франчайзи |
| Прочие сотрудники | **Только назначенные точки** (объединение по всем ролям) | Кассир, менеджер зала, бариста |

## Системная роль «Администратор»

- Одна на франшизу, создаётся автоматически, **неудаляема**, права не редактируются.
- Полный набор прав, включая доступ к кассе (`pos.access`).
- Выдаётся владельцу франшизы; может быть выдана владельцу партнёра при режиме «Полный доступ».

Разница между владельцем франшизы и владельцем партнёра — **не в роли** (у обоих может быть «Администратор»), а в scope.

## Типы франшизы

| Тип | Поведение |
|---|---|
| **Корпоративная** | Есть раздел «Юрлица», можно заводить партнёров, есть иерархия владения |
| **Индивидуальная (ИП)** | Одно главное ЮЛ, раздел «Юрлица» скрыт, создание партнёров запрещено |

## Вход и касса

- В админку и на кассу пускают по **правам**, а не по должности.
- Вход на кассу ([[POS Desktop]]) — по PIN сотрудника точки **плюс** наличие права `pos.access`. Нет права → на кассу не пустят.
