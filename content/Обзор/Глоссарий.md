## Организация и владение

| Термин | Определение |
|---|---|
| **Франшиза** | Бренд/сеть верхнего уровня. Одна установка ERP обслуживает много франшиз, данные изолированы. |
| **Франчайзи (партнёр)** | Предприниматель, работающий под брендом франшизы по её правилам. |
| **ЮЛ (юридическое лицо)** | Юрлицо/ИП, на которое оформлены точки и договоры. У франшизы одно главное ЮЛ; у партнёра — одно или несколько. |
| **Торговая точка (ТТ)** | Конкретное заведение (кафе/островок). Единица, к которой привязывают сотрудников, склад, кассу, меню. |
| **Scope (область видимости)** | Множество данных, которые сотрудник имеет право видеть. Считается по владению ЮЛ и назначенным точкам. См. [[Роли и доступ]]. |
| **Мультитенантность** | Изоляция данных: сотрудник одной франшизы никогда не видит данные другой. |

## Каталог и склад

| Термин | Определение |
|---|---|
| **Товар / Блюдо** | Позиция каталога. Бывает «блюдо» (готовится по техкарте) и «товар» (продаётся как есть). |
| **Категория** | Группа товаров в меню (иерархия). |
| **Модификатор** | Опция к товару (размер, добавка, соус). Бывает «свободный» (из справочника, переиспользуемый) и «закреплённый»/structural (уникальный для одного блюда). |
| **Прейскурант** | Набор цен. Один из них — по умолчанию. Разные точки/регионы могут иметь свой. |
| **Стоп-лист** | Список временно недоступных к продаже позиций на конкретной точке (например, закончился ингредиент). |
| **Ингредиент** | Сырьё/полуфабрикат со склада, из которого готовят блюда. |
| **Техкарта (рецептура)** | Из чего и в каком количестве состоит блюдо. Основа автосписания склада. Создаёт только франшиза. |
| **Складской остаток** | Сколько ингредиента есть на точке сейчас. |

## Заказы и касса

| Термин | Определение |
|---|---|
| **Заказ** | Покупка клиента: набор позиций, статус, сумма, оплата. См. [[Заказы]]. |
| **POS** | Point of Sale — касса. У нас это [[POS Desktop]] на Windows. |
| **KDS** | Kitchen Display System — кухонный экран с очередью блюд. См. [[KDS]]. |
| **Кассовая смена** | Рабочий период кассы между открытием и закрытием. По закону не длиннее 24 часов. |
| **X-отчёт** | Промежуточный отчёт по смене без её закрытия (сколько наторговали на данный момент). |
| **Z-отчёт** | Отчёт с закрытием смены (итоги за смену, обнуление). |
| **Чек** | Фискальный документ о продаже/возврате. |
| **Тендер** | Способ оплаты в конкретной операции (наличные / карта / СБП). |

## Оплата и фискализация

| Термин | Определение |
|---|---|
| **Фискализация** | Регистрация продажи в фискальном накопителе и передача в налоговую (через ОФД). Требование 54-ФЗ. |
| **Фискальный регистратор (ККТ)** | Устройство, печатающее фискальные чеки (у нас — АТОЛ). |
| **Касса 3 в 1** | Смарт-терминал, в котором кассовая программа, фискальная часть с накопителем и приём карт собраны в одном корпусе. Клиентское описание — [[Касса 3 в 1]]. |
| **ФН (фискальный накопитель)** | Защищённый чип внутри ККТ, хранит и подписывает чеки. |
| **Эквайринг** | Приём безналичной оплаты по карте. |
| **Эквайринговый терминал** | Устройство приёма карт (у нас — Unitodi P8 Bio). |
| **СБП** | Система быстрых платежей — оплата по QR/телефону. У СБП нет «отмены», только возврат. |
| **РНМ** | Регистрационный номер ККТ в налоговой. |
| **ОФД** | Оператор фискальных данных — посредник между кассой и налоговой. См. [[OFD]]. |

## Клиенты и лояльность

| Термин | Определение |
|---|---|
| **Клиент** | Гость сети (CRM). Главный ключ — телефон. См. [[Клиенты]]. |
| **Группа клиентов** | Сегмент: статический (руками) или динамический (по правилам). |
| **Штампы «N+1»** | Программа: накопил N покупок — получил награду (например, 6-й кофе бесплатно). |
| **Кэшбэк** | Начисление баллов процентом от чека, которые можно тратить. |
| **Уровни** | Ступени лояльности с разной ставкой кэшбэка (до 3 на франшизу). |
| **Реферальная программа** | Бонус за приведённого друга (на его первом заказе). |

## Доступ

| Термин | Определение |
|---|---|
| **Право (permission)** | Атомарное разрешение на действие (например, `catalog.edit`). |
| **Permission-роль** | Настраиваемый набор прав, назначаемый сотруднику. Заменяет фиксированные должности. |
| **Системная роль «Администратор»** | Неудаляемая роль с полным доступом, одна на франшизу. |
| **JWT / PIN / OTP** | Способы входа: токен сессии (JWT), короткий код на кассе (PIN), одноразовый код (OTP). |

## Интеграции и техническое

| Термин | Определение |
|---|---|
| **PayKeeper** | Партнёрская касса (фискализация + эквайринг). Не наша система. См. [[PayKeeper]]. |
| **POS Bridge** | Локальная программа на кассовой машине — «переводчик» между кассой и железом. См. [[POS Bridge]]. |
| **Агрегатор доставки** | Внешний сервис доставки еды, которому мы отдаём меню и стоп-листы. См. [[Агрегаторы доставки]]. |
| **Честный Знак** | Гос. система обязательной маркировки товаров. См. [[Честный Знак]]. |
| **.epf-обработка** | Внешний подключаемый модуль 1С. См. [[1C]]. |
| **Событие (event)** | Сообщение между сервисами («заказ оплачен», «стоп-лист изменён»). Так сервисы узнают об изменениях друг у друга. |
| **BFF** | Backend-for-Frontend — слой, который собирает данные из сервисов под конкретный экран. Бизнес-логики не содержит. |
