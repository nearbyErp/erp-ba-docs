**Домены** — бизнес-логика платформы: сущности, правила и процессы, на которых работают продукты (Админка, Касса, KDS). Каждая страница сверена с кодом соответствующего сервиса.

| Домен | Отвечает за | Заметки |
|---|---|---|
| [[Заказы]] | Жизненный цикл заказа (9 статусов), возвраты, агрегация продаж (X/Z, суточная сводка) | «дом» кассовой смены |
| [[Каталог]] | Товары, модификаторы (свободные и закреплённые), стоп-листы, прейскуранты | единый на франшизу |
| [[Склад]] | Техкарты (рецептуры), автосписание по продаже, остатки, приёмка | |
| [[Клиенты]] | CRM: клиенты (ключ — телефон), статические и динамические группы | полного UI в админке пока нет |
| [[Лояльность]] | Штампы «N+1», кэшбэк с уровнями, реферальная программа | развёрнуто |
| [[Пользователи и доступ]] | Сотрудники, permission-роли, области видимости, вход | permission-модель без «должностей» |
| [[Магазины]] | Торговые точки, столы зала, платёжный контур | зоны доставки/ETA — план, не в коде |

> [!tip] Читать сверху вниз
> Если знакомитесь с платформой впервые — начните с [[Заказы]] и [[Каталог]] (ядро продаж), затем [[Склад]] и [[Пользователи и доступ]].
