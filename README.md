# erp-ba-docs — База знаний НИРБИ ERP для бизнес-анализа

Статический сайт (Quartz v4) с бизнес-описанием платформы НИРБИ ERP для роли **бизнес-аналитика**.

## Что это

- Контент лежит в `content/` — авторские страницы на русском, **бизнес-язык** (без кода, эндпоинтов и схем БД).
- Каждая доменная страница написана из спецификаций vault `obsidian_erp` и **сверена с реальной кодовой базой** сервиса. Снимок сверки (репозиторий · ветка · срез) — в футере страницы.
- Структура: `Обзор` (карта, глоссарий, роли) · `Продукты` (Админка, POS Desktop, KDS) · `Домены` (заказы, каталог, склад, клиенты, лояльность, доступ, магазины) · `Интеграции` (PayKeeper, OFD, 1C, агрегаторы, POS Bridge, Честный Знак).

## Локальный запуск

```bash
npm ci
npx quartz build --serve   # http://localhost:8080
```

Сборка без сервера: `npx quartz build` → результат в `public/`.

## Актуализация контента

Страницы отражают срез сервис-репозиториев на **начало июля 2026**. При изменении сервиса:
1. Перечитать спеку в `obsidian_erp` + код сервиса.
2. Обновить соответствующую страницу в `content/`, поправить снимок сверки в футере.
3. Пересобрать (`npx quartz build`).

## Источники

- Спецификации: vault `obsidian_erp` (`forgejo.nirbi.ru/nirbi/obsidian_erp`).
- Код сервисов: репозитории `erp-*` на Forgejo (org `nirbi`).
